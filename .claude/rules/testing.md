# Testing rules
- Pyramid: many JVM unit tests (model, format, geometry, layout math) -> Robolectric + Roborazzi (UI, templates, rendering) -> few instrumented tests on the tablet (ink, real font metrics, IO, PDF) -> macrobenchmarks for budgets (P11).
- Names: `subject_condition_expectedResult`.
- Fakes over mocks (`core:testing`: FakeFolioFs, FakeClock, TestDispatchers, document builders). MockK only at framework edges.
- Flows with Turbine; assertions with Truth.
- Golden files in `testdata/` must stay small (< 1 MB each). Large fixtures are generated by test code.
- Record screenshot goldens only for intended changes; list them in the commit body ("goldens updated: ...").
- Instrumented tests run only via `bash scripts/device/instrumented.sh` against the debug package.
- Bug fix = failing test first. Randomized tests use fixed seeds printed on failure.
- Flaky test: fix it, or `@Ignore("FLAKY <id>")` + STATUS Deferred entry. Never add retry loops.
