# G3 Editor frame
Notewise 4.x, landscape 3200x2136 px, 1 dp = 2.75 px. Editor chrome was dark this session (system dark). New canvas created via FAB > Canvas, default page: grid paper, 218% zoom. Renamed to `Folio reference` (3 strokes on page 1, top-level of the library); later groups reuse it. Finger-draw mode and selected tool were restored (pen, finger mode off).

## Editor, pen selected (shots/G3-editor-pen.jpg)
- Layout: all chrome floats over the canvas as separate pills; no app bar. Canvas backdrop fills the screen; page centered (portrait page 2098 px = 763 dp wide at 218%).
  - Top-left nav pill: 188x44 dp at 8 dp from left, top edge at y 33 dp (below status bar). 5 buttons (home, page overview grid, add page, search, quick switch/tabs), 36 dp pitch, 24 dp icons.
  - Below it, 8 dp gap: edit pill 117x44 dp: undo, redo, finger-mode toggle (36 dp each).
  - Top-right pill 116x44 dp, 8 dp from right: note-mode (pen/view, selected = 36 dp circle #4E5058), Notewise AI (blue asterisk #38619C), more (3 dots).
  - Right edge under it: page scroll stepper 18x60 dp (chevron up/down in a thin pill).
  - Bottom-left pill 127x43 dp, 8 dp from left/bottom: page indicator as fraction ("1" over a rule over "2", 2 gray) | divider | zoom "218%".
  - Bottom center toolbox, two stacked pills, 8 dp apart, bottom edge 25 dp above the screen bottom:
    - Row 1 (tools) 747x44 dp: lasso (fixed, left) | divider | 19 scrolling tools at 36 dp pitch: pen, brush(fountain), highlighter, eraser, tape/washi, shapes, image, text (T in box), sticky note, emoji/sticker, table, web/link capture, camera/scan, ruler, mic (record), laser/sparkle, add-page-element, settings gear | divider | chevron (collapse row 2).
    - Row 2 (tool options, pen) 470x44 dp, centered over row 1: line type (curve) | 3 width presets (thin/medium/thick bars) | 7 color dots | sliders icon (tool details).
- Color:
  - canvas backdrop #252526; paper #FCFCFD, grid lines light gray (~#CACACA)
  - pill fill #292C31 (rows/nav), #2D3036 near row 1 center (slight gradient or noise); pill border 1 dp #4D4F57
  - divider #494B52 (2 dp wide, 26 dp tall in row 2; full-height in row 1)
  - icon enabled #D7D7DD (top) / #C1C3CC (toolbar); icon disabled #6F7177 (undo/redo with empty history)
  - selected tool: 36 dp circle #23496E behind the icon, icon tinted light blue
  - selected option dot under width/color: 4 dp circle #6F9DF5, 4 dp below the item
  - default pen palette: #010101, #EE894C, #914A65, #8BB83D, #6BA1D8, #CB4871, #2B4C9E
- Type: zoom "218%" sans (Roboto/MiSans-like), ~16 sp, regular, #E8E8EC; page fraction ~12 sp, current light, total gray #8F9196.
- Shape: every pill is a stadium (radius = height/2); 1 dp border, no visible shadow on the dark backdrop.
- Icons: 24 dp outline, ~2 dp stroke, rounded caps (Lucide-like); 36 dp hit circle; color dots ~20 dp (~).
- States: finger-mode toggle swaps icon (hand+arrows = finger scrolls; hand alone = finger draws), no toast. After drawing, undo icon turns enabled (#D7D7DD-ish), redo stays #6F7177. Selecting a tool morphs row 2 in place; row 2 width hugs its content (pen 470 dp, highlighter ~505 dp, eraser 244 dp) and stays centered on row 1.
- Ink: 3 finger swipes gave black strokes ~1 dp wide on screen at 218% (default pen = medium width, black).

- Header: page thumbnail 60x60 dp (radius ~6 dp, white page) at 16 dp padding; title "Neue Notiz 2026-10-01" ~16 sp medium #EDEDF0; 3 meta lines ~13 sp regular gray (pages, modified, created).
- Action tiles row (horizontally scrolling): 75x75 dp tiles, 5 dp gap, fill #2B3C5D (#233454 at edges), radius ~8 dp (~); 24 dp outline icon over a ~13 sp label, both light: Share, Export, Rename, Go to page.
- List rows 46 dp tall, full width: 20 dp outline icon at 16 dp, label at 56 dp, ~15 sp regular #E6E6EA: Change template, Scrolling and layout, Stylus and finger, Settings. No dividers.
- Default note name: "Neue Notiz YYYY-MM-DD"; a new canvas starts with 2 pages.
