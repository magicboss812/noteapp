# G5 Editor panels and sheets
Device UI language is German (labels translated here); Notewise is in its dark theme (editor chrome dark, page white grid). 1 dp = 2.75 px. Patterns: surfaces #212326..#26282C, accent #6795EC..#72A0F8 with on-accent #102B6E, selection = blue label + trailing check (no row tint), menus ~42 dp rows, dialogs centered ~16 dp radius, 24 dp circular close button. Not captured: overview "select" mode, bookmark-filled state, page-size preset list.

Header right: 5 buttons 40x40 dp each, no gaps: add (+), select (check in circle), undo, redo (disabled = dim gray), close (x in a 24 dp filled circle #26282C-ish, glyph #92939D).
- Color: card body #232529, header #1E2023, header divider #4A4C53, title/enabled icons #DBDBE1, disabled undo/redo ~#5A5C63 (dim), page number text #C4BFC9, selected thumbnail border #6795EC.
- Type: header title sans (Roboto-like) ~18 sp medium #DBDBE1; page number "1" ~16 sp regular #C4BFC9 followed by a 20 dp chevron-down (page menu).
