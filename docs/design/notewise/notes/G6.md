# G6 Settings and themes
Device: landscape 3200x2136 px, 1 dp = 2.75 px. Notewise UI in German. Default theme = "Systemstandard" (system dark), so G1..G5 are dark; this group adds the light variant via the in-app theme switch, then restores Systemstandard.

## Settings home, dark (shots/G6-settings.jpg)
- Layout: full-screen page (not a dialog). Top app bar 64 dp tall: back arrow at left (touch 56x64 dp, icon ~24 dp at x 36 dp), title "Einstellungen" centered. Content = single centered column of section cards, 663 dp wide (1824 px) on a 1164 dp screen; first card top at ~107 dp; card gap ~8 dp (preview 290->312 px). Sections: Allgemein (Sprache, Thema), Notewise AI (gated rows + sign-in button), Notizen (Standardansicht, new-note name format), more below (scroll).
- Card inner: text inset 20 dp from card left; section title row 30 dp; plain row 48 dp (132 px) tall; row with subtitle 55 dp (150 px); value-on-right rows show value text + chevron-down 20 dp (dropdown trigger, 99x48 dp to 152x48 dp); navigation rows show a chevron-right ~20 dp at the right edge (right inset ~28 dp).
- Color: page bg #070708 / #050505 (near black, flat, no gradient); app bar same bg #0A0A0B. Card fill blue-slate with fine noise grain, slightly lighter at top: #373C4D (top) / #34394A / #313646..#2E3343 (bottom). Section title #E5E0E9. Row label #E0E0E7-ish (Sprache), value text #DFDFE6. Back arrow #C6C1CC. Disabled row label #8E8E94 (subtitle #818287..#8B8B90). Notice/error text salmon #F4B9B1 (#EBB0A7). Sign-in button: horizontal gradient #4D86E1 (left) -> #637DDF (mid) -> #8577E0 (right, violet), label dark #343332, medium weight.
- Type (all sans, Roboto-like): app bar title ~20 dp regular #E0E0E7; section title "Allgemein" ~22 dp bold (cap height 42 px), line 30 dp; row label ~15 dp regular; subtitle ~13 dp regular; notice line ~13 dp medium with slight letter spacing; button label ~15 dp medium.
- Shape: card radius ~8 dp (~)(corner ~22 px), no border, no visible shadow on the dark bg. Sign-in button 623x48 dp, fully rounded (24 dp), inset 20 dp from the card edges.
- Icons: chevrons outline ~20 dp, stroke ~2 dp, color = text color of the row (dimmed on disabled rows).

## Theme dropdown menu, dark (shots/G6-theme-menu.jpg)
- Layout: popup anchored below the value trigger, left edge ~8 dp left of the value text, overlapping the card edge and the next card; 202x125 dp; 3 items 42 dp tall: leading icon 24 dp at 13 dp inset, label at 40 dp, trailing check at the right for the selected item. Items: Hell (sun), Dunkel (moon), Systemstandard (half-filled circle).
- Color: menu fill #232529 (top) -> #1D1F22 (bottom), darker than the cards and neutral (not blue-slate). Item text + icon #E1E1E8. Selected item text, icon and check accent blue #6C97EB (check #5E82C6, thinner antialiased). No border.
- Type: item label ~16 dp medium (semi-bold look), sans.
- Shape: radius ~12 dp (~); soft dark shadow below (visible over the black gap, ~8 dp blur).
- Theme is an in-app switch with 3 options; default Systemstandard.

## Settings home, light (shots/G6-settings-light.jpg, G6-settings-light-2.jpg, G6-settings-switches.jpg)
- Layout identical to dark (same sizes, positions, grain). Further sections when scrolled: Notizen (default view, new-note name format with value dropdown), Canvas (switch rows: continue at last page, keep screen on, hide system bars; nav rows: Scrollen und Layout, Werkzeugkasten, Link, Zum Ausrichten einrasten), Sicherheit (Passwort), Speicher verwalten (Notizen 387 MB / Cache 423 MB as label + value + 12 dp description, text button "Cache leeren" bottom right), Über.
- Color: page bg #FAFAFB / #F8F8F8 (near white, fine grain). Card fill pale blue-grey #F0F3FA (top) / #EDF0F7 / #E7EDF6..#E7EAF0 (lower); no border. Section title #27252A. Row label / value #1B1B1F. Back arrow #4B4851. Disabled label #8E8E94 (same as dark). Notice/error text red #D4504A (#CB4740). Sign-in gradient identical (#4D86E1 -> #8577E0) but label turns light #F5F3ED (dark #343332 in dark theme). Text button "Cache leeren" accent #4C86E1, no fill, ~15 dp medium.
- Switch (Material 3 style): track 52x32 dp, fully rounded. On: track #4A84DF..#4E88E3, thumb 24 dp #FCFCFD. Off: track fill #DEE6F1 (card tint), 2 dp outline #6F7079..#73747D, thumb 16 dp #73747D. Switch right edge ~28 dp from card edge; switch rows 48 dp (label + 13 dp subtitle).
- Type: same sizes as dark; storage value ("387 MB") ~15 dp regular aligned in a second column ~40 dp after the label.

## Sub-page "Werkzeugkasten" (toolbox), light (shots/G6-toolbox-light.jpg)
- Layout: same app bar (title = page name, centered) and 663 dp centered card column. Card 1: one dropdown row "Position der Werkzeugleiste" -> "Unten" (68 dp card: 48 dp row + 10 dp padding). Card 2: header row "Werkzeuge neu anordnen" (section title style) with a right-aligned accent text button "Auf Standard zurücksetzen"; below, a reorderable list of tools: Stift, Kreativpinsel, Textmarker, Radiergummi, Klebeband, Form, Bild, Textfeld, ... (list scrolls inside the card; bottom ~10 dp fades into the card tint).
- List item: 623x44 dp, inset 20 dp from the card sides, 8 dp gap (52 dp pitch). Leading tool icon 24 dp at 13 dp inset; label at 41 dp; trailing: eye-off visibility toggle (36 dp touch, icon 24 dp) and a 6-dot drag handle (36 dp touch, dots ~2 dp) ~8 dp from the right edge.
- Color: item fill #FCFCFD (near white) on card #EDF0F7; tool icon #42434A..#484951; label #4A4B53..#52535C (softer than row labels); eye-off icon #4C4D55; drag-handle dots #70717A..#7A7B85 (lighter). Text button #4C86E1-family accent.
- Type: list label ~15 dp regular; header ~22 dp bold.
- Shape: item radius ~10 dp (~), no border, no shadow. Icons outline, Lucide-like rounded caps, stroke ~1.75 dp (~).

## Sub-page "Scrollen und Layout" + dropdown, light (shots/G6-scroll-layout-menu.jpg)
- Layout: one card with 3 dropdown rows (Position der Bildlaufleiste: Rechts; Scrollrichtung: Vertikal; Seitenlayout: Einzelseite), card = 3x48 dp rows + ~10 dp top/bottom padding; rest of the page empty bg.
- Dropdown menu (light): 200x84 dp, 2 items of 42 dp; top edge 2 dp below the card bottom, right edge ~50 dp past the trigger chevron (menu starts under the value text). Leading icon 20-24 dp (filled glyph style for page-layout icons), label at ~40 dp, check right.
- Color: menu fill #FAF9FA..#FDFCFD (near white, not the blue card tint); item text #1A1A1E; selected text/icon/check #4B85E0; shadow soft grey (#EFEFF0 just below edge), ~4 dp offset, ~8 dp blur, low opacity.
- Shape: menu radius ~12 dp (confirmed in both themes). Light theme menu (shots/G6-theme-menu-light.jpg) has the same layout: selected "Hell" in accent blue with check, other items near black; menu right edge may run past the card when the trigger is short.
- Theme restored to Systemstandard at the end of G6.

## Library home, light (shots/G6-home-light.jpg)
- Layout: identical to the dark home (sidebar 280 dp, greeting, chips row, sort/view/select icons, 4-column folder/note grid, FAB bottom right, search+infinity capsule top right, settings gear bottom left of sidebar).
- Color: sidebar bg flat #F3F3F3..#F5F5F5 (bottom #F1F1F0), no divider line, just the tone step to the content. Content bg near white #FEFEFF..#F7F7F7 with the "expressive" top band: blue gradient #88AFE6 (top center, under the status bar) fading via #CDE3EE / #E8F0F9 to white by ~y 220 dp; white dot grid in the blue band (dark theme: dots on slate). Selected nav pill #DEDEE2 (grey, not blue), selected nav text/icon #518BE7; inactive nav text #4C4D55. Greeting #1F1F23..#222227; chip "Alle" selected fill #E6EEF5..#E9F1F8 (very pale blue) with accent text; unselected chip text #242429. Search capsule fill #FDFCFD with soft shadow. FAB #4B85E0 with white +. Note card (Folio reference) white #FEFDFE, 1 dp border #EBEBEC, grid-paper thumbnail fills the card body.
- Folder colors are lighter/brighter in light theme (~): Geo #98ED85, Sport #5EAE7C, Physik #A5426F, Mathe #5BACC9 (dark: Geo #74C662, Physik #7C1F45, Mathe #4088A6).
- Type: greeting "Guten Tag" is a SERIF display face (Literata/Source Serif-like), ~36 dp semibold; card titles serif too (same as dark); subtitle and chips sans.
## Settings "Über" (about) section, dark (shots/G6-settings-about.jpg)
- Layout: last card: title "Über", 4 text-only link rows 48 dp (Nutzungsbedingungen, Datenschutzerklärung, Hilfe, Diagnosedaten freigeben; no chevrons), then a footer line "Version: 4.0.4 (40016)" with a copy-to-clipboard icon button (20 dp icon, 44x48 dp touch) ~12 dp after the text.
- Color: link rows #D8D8DE..#DDDDE4 on card #313646; version text dimmer grey (~); copy icon #9FA1AA (outline, two overlapping rounded squares).
- Type: link rows ~15 dp MEDIUM (heavier than value rows); version ~15 dp regular.
- Empty/error states: none new seen in settings; the gated AI rows show the disabled style (#8E8E94) plus the salmon/red notice line instead of an error dialog.

## Editor, light (shots/G6-editor-light.jpg)
- Layout: identical to dark editor (top-left nav pill + undo/redo/finger pill, top-right mode/AI/more pill, bottom two-row toolbar: row 2 floating pill above row 1 pill, page indicator + zoom bottom left).
- Color: canvas surround #EEEEEF..#EFEFF0 (flat light grey); page #FDFDFE with grid lines #D9D9D9. Toolbar pills fill #F9F9FA..#F5F5F5 (near white) with a soft grey shadow (#D1D1D1 at the pill bottom edge, gone by ~4 dp below). Pill dividers #E6E6E6..#ECECED. Tool icons #1F1F23..#343438; width-line glyphs #4A4B53..#4D4E56. Selected tool: pale blue circle #C6DBF7..#C8DDF9 with dark navy icon #12263B. Selected width/color indicator dot #528CE8. Active note-mode button (top right): grey circle #EDEDEE. Disabled undo/redo icons light grey.
- Shape/type: same as dark (pills fully rounded, 36 dp circles).

- Theme switch mapping summary: dark surfaces (#070708 page, #1A1A1B sidebar, #373C4D cards, #232529 menus) -> light (#FAFAFB page, #F3F3F3 sidebar, #EDF0F7 cards, #FAF9FA menus). Accent stays ~#4B85E0..#72A0F8 (lighter in dark).
