# G2 Library organization
Device: landscape 3200x2136 px, 1 dp = 2.75 px. Notewise UI language is German; app was in dark theme.

## Folder (breadcrumb) (shots/G2-folder.jpg)
- Layout: same frame as home (sidebar 280 dp, greeting header stays). Filter chips row is replaced by a breadcrumb at the same y (row 52 dp tall): home icon button 52 dp, chevron, folder name text button (48 dp tall). Sort / grid-list / select buttons stay right-aligned on the same row.
- Layout: note card in a folder: 195 dp square, 4 per row, gutter ~24 dp (card centers 602 px apart = 219 dp). Header 66 dp (timestamp line + 1-2 line title, options button 40 dp at top right), 1 dp divider, then the page thumbnail fills the rest edge to edge (no inner padding). Header text inset 10 dp left, 10 dp top.
- Color: page background #010101..#040405 (near black; a dark blue glow #18222F at top center behind the header), card header surface #202225, card border and header divider #474950 (~1 dp), thumbnail paper #FDFDFE.
- Color: breadcrumb current segment (accent) #6A98EF, home icon and chevron #E2E2E9.
- Color: card timestamp #8D8D93, card title #DCDCE2. FAB fill #163175-ish edge / #FBFBFC glyph (light blue FAB, white plus).
- Type: card title serif bold (~Literata/Source Serif style), ~15 sp, line ~16 dp, max 2 lines with ellipsis; card timestamp sans regular ~11 sp ("22. Sept., 15:09"). Breadcrumb text sans medium ~16 sp (~).
- Shape: card radius ~16 dp (~), 1 dp border #474950; thumbnail clipped by the card radius at the bottom.
- Icons: breadcrumb home icon outline ~24 dp, stroke ~2 dp (Lucide-like house), chevron-right ~16 dp.

## Card overflow menu (shots/G2-card-menu.jpg)
- Layout: popup anchored to the card's "..." button: its top-left sits just below/left of the button (button at card top right; menu left edge ~10 dp left of the button, top ~30 dp below it), overlapping neighbor cards. Width 200 dp, 7 rows of 42 dp, ~6 dp vertical padding (291 dp total). Row: icon 20 dp at 20 dp inset, label starts 40 dp after the menu edge (icon-to-text gap ~14 dp).
- Items (note): Open in split view, Favorite, Rename, Lock note, Move to, Duplicate, Delete (last, danger color). No dividers.
- Color: menu surface #1D1F22 (pressed/hover row #202225..#232529), label text #E1E1E8, icons same as text, danger label + icon #F3B8B1 (light salmon, no red fill). No visible border on dark; soft shadow.
- Type: labels sans regular ~16 sp (Roboto-like).
- Shape: radius 16 dp (~), no border.
- Icons: outline 20 dp, stroke ~1.75 dp: columns, star, pencil, lock (filled body), folder-arrow, copy-plus, trash.
- States: opening the menu does not dim the background (no scrim); the long label truncates with "...".

## Rename dialog (shots/G2-rename.jpg)
- Layout: centered horizontally, pushed up above the IME (top at 100 dp from screen top). Width 560 dp, height 240 dp. Title centered at top (~25 dp from top edge). Outlined text field 24 dp side inset, 56 dp tall, full width; character counter "26/100" right-aligned below the field (~12 sp, secondary color). Buttons bottom-right, text-only: "Cancel" then "Rename" (each 48 dp tall, ~8 dp gap, 24 dp right inset).
- Color: scrim darkens the page to ~45% (card thumbnail #FDFDFE reads #ADADAE, panel #1E1E1F reads #171718). Dialog surface #222428..#25272B. Field focused border accent #6A98EF, field fill = dialog surface. Selected text highlight #877DA3 (muted violet). Title and button labels light (#E1E1E8-ish); confirm label not accent-colored.
- Type: title sans regular ~20 sp; field text sans regular ~16 sp; buttons sans medium ~15 sp.
- Shape: dialog radius ~16 dp (~), no border; field radius ~4 dp, focused border 2 dp.
- States: opening selects the whole name and opens the keyboard.

## Move dialog (shots/G2-move.jpg)
- Layout: centered modal 560 dp wide x 655 dp tall (nearly full height, ~28 dp top/bottom margins). Header row 52 dp: back button (52 dp, only when inside a subfolder) left, title centered, close button right (circular 24 dp chip inside a 48 dp target). Body: folder list, row 48 dp, full width; folder icon 29x24 dp at 24 dp inset, name starts 64 dp from the row's start (~35 dp after the icon). Footer: one right-aligned text button "Move to Home" (truncated label, 48 dp tall, 24 dp right inset).
- Starts in the current folder; an empty folder shows a centered zero state: "This folder is empty." (secondary text) + a pill "Move to Physik" + text button "Create folder".
- Color: dialog surface #202225..#26282C, scrim like rename. Close chip fill #2C2C2E..#353538 with x glyph #8C8D96. Row name text #DCDCE2.
- Color: folder colors are per-folder fills (filled folder glyph, darker back tab): #AB7C86 dusty rose, #DB6945 orange, #EABE4D yellow, #87F06E green, #430D73 deep purple, #4CA2C8 blue, #EB6CA6 pink, #BA5522 burnt orange, #96244F berry, #479A5D green.
- Type: title sans regular ~20 sp centered; row names sans regular ~16 sp; footer button sans medium ~15 sp, light (not accent).
- Shape: dialog radius ~16 dp (~); folder glyph corner radius ~3 dp; no row dividers, no row backgrounds.

## Delete (shots/G2-deleted-snackbar.jpg)
- "Delete" in the card menu moves the note to the Bin immediately: no confirmation dialog, no snackbar, no undo; the grid just reflows (cards shift left, no visible animation captured). (The note was restored from the Bin right away.)

## Bin (shots/G2-bin-menu.jpg; Bin tab itself also in G1)

Under the chip row a full-width info banner 52 dp tall (same width as the grid): text left "Items in the bin are deleted permanently after 14 days.", text button right "Empty bin". Then the card grid (cards keep the normal header + thumbnail).
- Card: a centered pill at the thumbnail bottom (~8 dp above the edge) "13 days" (pill ~26 dp tall, ~8 dp horizontal padding, fill #1D1D1D, accent text #6A98EF, ~12 sp).
- Bin card menu: 2 rows (42 dp each, same style as the card menu): "Restore" (history-clock icon, light text) and "Delete permanently" (trash, danger #F2B7B0). Width ~200 dp, surface #25272B, radius 16 dp (~). The menu opens below-left of the "..." button and overlaps the card thumbnail.
- Color (Bin) info banner fill #212124..#242427 (radius ~8 dp (~)), banner text secondary light, "Empty bin" #D7D7DD medium. Selected filter chip fill #263757..#2A3B5C (dark navy), its label accent #6A98EF.

## Multi-select mode (shots/G2-multiselect.jpg)
- Enter: the check-circle button at the right end of the control row (tapping a card then toggles it). The grid/list toggle hides; the select button turns into a filled navy circle (52 dp, fill #243555..#2C3D5E, check glyph accent #628CDF).
- Card: the "..." button is replaced by a selection circle 28 dp at the same spot: unselected = outline ring ~1.5 dp light gray on the header; selected = filled accent circle #6893E5 with a dark check. Card itself does not change (no tint, no border change).
- Bottom action bar: floating stadium pill centered on the content column, 557 dp wide x 69 dp tall, bottom 28 dp above the screen edge, overlaps the grid. Fill #2F363F..#363D47 (slate blue-gray), 1 dp border #46484F. 5 equal-ish buttons, icon 24 dp above label: Cancel (x), Select all (check-circle), Delete (trash), Move to (folder-arrow), Export (upload). Delete is not danger-colored here.
- Type: bar labels sans medium ~14 sp #DFDFE6; icons same color, outline ~2 dp stroke.
- States: no count label ("n selected") anywhere; title row (greeting) unchanged.

## Search overlay with results (shots/G2-search.jpg)
- Layout: full-screen overlay (covers the sidebar too), opened from the search icon in the top-right capsule. Top bar 72 dp: back arrow 24 dp at 24 dp inset, borderless query field (text ~18 sp) filling the row, clear "x" at the right; 1 dp divider #46484F under it. Results update live while typing (thin progress bar under the divider).
- Upsell banner (Notewise-specific, skip for Folio): full width minus 8 dp, 60 dp tall, radius ~12 dp, fill #333643 (~), text #9F9DA9, accent text button.
- Section header "Notes" sans medium ~16 sp, 12 dp inset. Results in 2 columns (each 572 dp wide), row 95 dp: thumbnail 50 dp square (paper preview, radius ~4 dp) at 10 dp inset; text column 36 dp from the thumbnail: title sans regular ~18 sp #E1E1E8, context line (folder/page title) sans medium ~14 sp #A9A9B0-ish, snippet ~14 sp secondary, 1-2 lines, starts with "…"; "..." overflow button 52 dp at the row end. No dividers, no row backgrounds.
- Color: overlay background #1C1E21..#25272B (solid, the home gradient is gone), match highlight fill #F3F350 (bright yellow) behind dark text (#080809) in title and snippet.
- Type: all sans (Roboto-like); no serif in search.

## Tags (sidebar section) and new-tag dialog (shots/G2-new-tag.jpg)
- Sidebar: "Tags" section header row 52 dp (label sans medium ~18 sp left at 30 dp inset (~), "+" icon button 52 dp right); the list below is empty for this user (no empty-state text). Notewise has no Tags tab in the filter chips: tags live in the sidebar only.
- New-tag dialog: centered (vertically too, no IME), 476 x 288 dp, radius ~24 dp (~), surface #24262A, scrim as other dialogs. Header: title "New tag" centered (~20 sp), circular close chip (24 dp, fill #353538, x #8E8F99) at the top right.
- Color row: 6 preset dots + 1 custom, dot 36 dp, pitch 40 dp (4 dp gap), centered. Presets: #6F9BF0 blue, #96D785 green, #EABE4D yellow, #ED983D orange, #E36F63 coral, #D37AF6 violet; custom = conic rainbow wheel dot. Selected = white check glyph (~20 dp) on the dot, no ring.
- Name field: pill 200 x 41 dp, fill #34394A, no border, text centered ~16 sp light, prefilled with the color's name ("Blue").
- Primary button: filled pill 105 x 48 dp (~), fill accent #6896ED, label dark navy #0E296C sans medium ~16 sp ("Create"), centered under the field. Gaps: header -> dots ~26 dp, dots -> field ~24 dp, field -> button ~30 dp.
- So dialogs come in two styles: Material-like (rename, create folder: outlined field, text buttons right) and Notewise-style (new tag: centered, close chip, pill field, filled accent pill button).
