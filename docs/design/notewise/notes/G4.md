# G4 Editor tool options
Device landscape 3200x2136 px, 1 dp = 2.75 px. Notewise app UI language is German. Editor chrome is dark on light paper (grid template).

## Color popover (shots/G4-color-popover.jpg)
- Trigger: tap the already-selected color dot in the pen quick row (row 2). Popover floats above row 2, horizontally centered on the tapped dot, gap ~6 dp above the row-2 pill.
- Layout: card 921x287 px = 335x104 dp. Header row: title "Farbe" left (16 dp inset), at right two 36 dp icon buttons: + (add custom color) and list icon (edit palette). Second row: 7 color dots in 36 dp cells, then a 2 dp vertical divider, then a rainbow conic "color picker" dot. Overflowing palette scrolls horizontally (a partial dot peeks at the right edge before the divider).
- Color: popover bg #1D1F22; title text ~#C0BBC5 (sampled on glyph, true ~#C8C8D0 (~)); icons #DEDEE5; selected-dot ring #46484F..#4A4C53.
- Palette (popover): #040404 black, #B6261A red, #5DC4F2 sky, #64CD44 green, #F5CB4E yellow, #ED884B orange, #891EEE violet.
- Type: title sans (Roboto-like), ~16 dp text height 44 px box, regular, light gray.
- Shape: card radius ~18 dp (50 px), no visible border, no visible shadow on light paper (flat dark slab).
- Dots: unselected 61 px = 22 dp filled circle; selected 73 px = 26.5 dp fill inside an 87 px = 32 dp gray ring (ring ~2.5 dp, gap ~2 dp... ring hugging fill with dark gap). Cell 36 dp.

## Shared patterns (all G4 screens)
- Interaction: tap the selected row-2 item to open its popover (color, width); tap again or outside to close; one tap outside only closes, it does not act. Details icon opens a per-tool settings panel; every panel = title + close, preview box, slider(s) with value capsule, divider, 44 dp setting rows, color section at the bottom.
- Surfaces: popovers/panels/dialogs #1C1E21..#222428 (one surface tone, slight sensor noise), radius ~18-20 dp, flat on dark chrome, soft shadow visible on paper. On-canvas bars (selection, text) are near-black #1C1C1C..#232324 with a 1 dp #4B4D55 border.
- Accent: blue family: selected fill #20466B..#23496E, strong accent #6B99F0..#6E9CF4, selection/outline on paper #4997F3. Destructive: salmon #EFB4AD..#F3B8B1 text/icons, no red fills.
- Selection states: tool = filled dark-blue circle; row-2 option = 4 dp blue dot under it (pen) or a 2 dp blue ring (eraser sizes) or blue icon tint (lasso modes); cards = 2 dp blue border + dark-blue fill; segmented = dark-blue segment.
