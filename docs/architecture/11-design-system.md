# 11 Design system
Direction: calm, bright, modern tablet UI heavily inspired by the Notewise screenshots in `docs/design/reference/` (see its README for what to take). Folio has its own name, copy, icons, and colors; no Notewise assets or wording are reused.

## Principles
- Content first: the page is the brightest, calmest surface; chrome is light, grouped into soft pills, and floats.
- Few colors: one blue accent, neutral grays, ink colors only on content.
- Big, forgiving targets for pen and finger (>= 44 dp) with small visual glyphs (22 dp icons).
- Motion explains state changes; nothing bounces for fun.

## Spacing and shapes
- Spacing scale (dp): 2, 4, 8, 12, 16, 20, 24, 32, 40, 48. Screen side padding 24 (landscape) / 20 (portrait).
- Radii: xs 6, s 10 (chips), m 14 (toolbar pills), l 16 (cards), xl 24 (sheets), full (color dots, round buttons).

## Elevation
- Cards: 1 dp border + shadow y 1, blur 3, black 4%. Hover/press: shadow y 4, blur 12, 8%.
- Floating toolbar pills and row 2: shadow y 6, blur 20, 10%; no border in dark mode, border in light.
- Pages on the canvas: 1 dp border #E3E6EB + shadow y 2, blur 8, 6%.
- Sheets: shadow y -4, blur 24, 12% plus scrim 32% (dark 48%).

## Motion
| Token | Value | Used for |
|---|---|---|
| fast | 120 ms, standard easing | press states, icon swaps, chip selection |
| standard | 200 ms, standard easing | options row changes, menus, tab indicator |
| emphasized | 320 ms, emphasized decelerate | sheets, card -> editor container transform, split view open |
| spring | dampingRatio 0.85, stiffness 500 | toolbar dock snapping, floating toolbar drag release, selection box |
Easing: standard = CubicBezier(0.2, 0, 0, 1); emphasized decelerate = CubicBezier(0.05, 0.7, 0.1, 1).
- Card -> editor: shared element (card bounds -> page area), cover image crossfades into the live first page.
- Tool switch: selected background slides between tools (shared indicator), icon scales 0.92 -> 1.
- Options row: AnimatedContent, fade + 8 dp horizontal slide.
- Page add/delete: fade + 0.96 -> 1 scale; page panel reorder: animateItem.
- Predictive back from the editor to the library.
- Reduce motion setting: all durations x 0.5 and no container transform (crossfade instead).
- Never animate content during inking; animations must not delay input handling.

## Library screen
Reference: `library-reference.png`. Landscape layout:
- Left sidebar 280 dp (collapsible to 72 dp rail): app name + collapse button, Home, folder tree (expand/collapse chevrons, tint dot, counts), New folder, and Settings at the bottom.
- Header: greeting "Hello, <name>" (displayLarge; plain "Your notes" if no name set) and a date subtitle ("Saturday, 26 September") in textSecondary. Top-right: round search button (40 dp, surface, border) and "New" button (accent, pill).
- Tabs row: segmented chips All, Favorites, Tags, Bin (selected: accentSoft background + accent text). Right side: "Sort: Recent" dropdown, grid/list toggle, select-mode check button.
- Grid: 3 columns landscape, 2 portrait (adaptive min width 280 dp), gutters 20 dp. Background: `background` + backgroundGlow.
- Portrait: sidebar becomes a modal drawer opened from a menu button left of the greeting.

## Cards
- NoteCard: surface, radius 16, 1 dp border, padding 20, min height 240 dp. Top line: caption timestamp ("Today, 1:21 PM" / "Yesterday" / date) and an overflow button. Title: cardTitle, max 2 lines. Preview: cover thumbnail (radius 10, border) for ink/PDF documents, or up to 10 lines of textPreview rendered as mini Markdown (bold headings, bullets) in bodySmall. Favorite star and tag chips at the bottom when present. Selected (open in other pane or multi-select): 2 dp accent border.
- FolderCard: tinted background, stacked-paper illusion (two offset white sheets behind a front sheet showing the latest note's title and first lines, faded at the bottom), caption "12 notes", folder name as cardTitle.
- List mode: 64 dp rows with small thumbnail, title, folder, modified time.

## Sticky notes
Colors: yellow #FDE68A, pink #FBCFE8, blue #BFDBFE, green #BBF7D0, lavender #DDD6FE. Radius 4 pt, shadow y 2, blur 6, 12% (drawn in page space so it exports), optional rotation up to ±4 deg. Text uses the flow's font at body size, textPrimary ink #1F2937.
